# ORRA

**A clearer view of you.**

Self-understanding + personalized Vedic astrology in one calm space.

## What is ORRA?

ORRA helps you:
- Talk freely and see patterns over time (self-reflection)
- Get birth-chart based guidance (Astro)
- Track a structured Clarity Quotient across 6 life dimensions
- Stay private and judgment-free

Inspired by the depth of Brihas + the personalization of Melooha — combined into one peaceful experience.

## App structure

| Tab | Purpose |
|-----|--------|
| **Today** | Daily clarity snapshot + sky insight |
| **Talk** | Conversational self-understanding |
| **Astro** | Birth chart, daily guidance, ask questions |
| **Patterns** | ORRA Quotient + mind map |
| **You** | Profile, privacy, journey |

## Design

Soft, calm, peace-to-the-eyes palette:
- Warm off-white backgrounds
- Soft sage accent
- Warm sand highlights
- Generous whitespace, quiet typography (DM Sans)

## Tech

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Mobile-first responsive + PWA-ready

## Local development

```bash

```
